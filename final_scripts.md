# Окончательные пользовательские сценарии ActiveHabit

## Автор

Водяников Александр Сергеевич, 11И7

## Сценарий 1. Регистрация пользователя

1. Пользователь открывает приложение.
2. Пользователь переходит на экран регистрации.
3. Пользователь вводит имя, адрес электронной почты и пароль.
4. Приложение проверяет корректность введённых данных.
5. Если данные введены неверно, приложение показывает сообщение об ошибке.
6. Если электронная почта уже зарегистрирована, сервер сообщает об этом пользователю.
7. Если данные корректны, сервер создаёт учётную запись.
8. Пользователь переходит к работе с приложением.

## Сценарий 2. Вход и сохранение авторизации

1. Пользователь открывает экран входа.
2. Пользователь вводит электронную почту и пароль.
3. Приложение отправляет данные на сервер.
4. Сервер проверяет пароль и возвращает токен авторизации.
5. Приложение сохраняет токен на устройстве.
6. Пользователь переходит на главный экран.
7. После повторного запуска приложения пользователь остаётся авторизованным, если токен действителен.

## Сценарий 3. Просмотр профиля

1. Авторизованный пользователь открывает раздел профиля.
2. Приложение отправляет защищённый запрос с токеном авторизации.
3. Сервер определяет пользователя по токену.
4. Приложение отображает данные профиля.

## Сценарий 4. Создание и просмотр привычки

1. Пользователь открывает раздел привычек.
2. Пользователь нажимает кнопку добавления привычки.
3. Пользователь вводит название привычки.
4. Приложение проверяет введённые данные.
5. После сохранения привычка передаётся на сервер.
6. Созданная привычка появляется в списке пользователя.

## Сценарий 5. Отметка выполнения и серия привычки

1. Пользователь открывает список привычек.
2. Пользователь выбирает привычку и отмечает её выполнение за текущий день.
3. Приложение отправляет отметку на сервер.
4. Сервер сохраняет дату выполнения.
5. Приложение обновляет состояние привычки и серию выполнений.
6. Повторная отметка за тот же день не создаёт второе выполнение.

## Сценарий 6. Удаление привычки

1. Пользователь открывает раздел привычек.
2. Пользователь выбирает привычку, которую хочет удалить.
3. Пользователь нажимает кнопку удаления.
4. Приложение отправляет запрос на сервер.
5. Привычка удаляется и исчезает из списка пользователя.

## Сценарий 7. Добавление тренировки

1. Пользователь открывает раздел тренировок.
2. Пользователь нажимает кнопку добавления тренировки.
3. Пользователь выбирает вид тренировки.
4. Пользователь указывает продолжительность тренировки.
5. Если выбрана пробежка, пользователь также вводит дистанцию в метрах.
6. Приложение проверяет, что значения заполнены корректно.
7. После сохранения данные отправляются на сервер.
8. Тренировка появляется в истории пользователя.

## Сценарий 8. Просмотр истории тренировок

1. Пользователь открывает раздел тренировок.
2. Приложение запрашивает данные пользователя с сервера.
3. Сервер возвращает сохранённые тренировки.
4. Приложение отображает историю тренировок с их видом, продолжительностью и дистанцией для пробежек.

## Сценарий 9. Просмотр статистики

1. Пользователь открывает раздел статистики.
2. Приложение загружает сведения о тренировках и привычках.
3. На экране отображается количество тренировок.
4. Отображается суммарная продолжительность тренировок.
5. Отображается общая дистанция пробежек.
6. Отображается статистика выполнения привычек.

## Сценарий 10. Получение помощи и выход из аккаунта

1. Пользователь открывает раздел помощи.
2. Приложение показывает описание основных функций и действий пользователя.
3. Пользователь переходит в профиль.
4. Пользователь нажимает кнопку выхода.
5. Приложение удаляет сохранённый токен авторизации.
6. Пользователь возвращается на экран входа.
