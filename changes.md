# Изменения проекта ActiveHabit

Основная идея проекта сохранилась: ActiveHabit является Android-приложением для учёта тренировок, пробежек и полезных привычек. Во время разработки состав функций был изменён, чтобы основные пользовательские сценарии работали стабильно и использовали удалённый сервер и базу данных.

## Изменение 1. Автоматическое создание плана тренировок

**Планировалось:** пользователь выбирает цель и уровень подготовки, после чего приложение автоматически создаёт план тренировок.

**Реализовано:** пользователь самостоятельно добавляет фактически выполненную тренировку, выбирает её вид и указывает продолжительность.

**Причина:** автоматическое составление безопасного и подходящего пользователю плана требует отдельной системы рекомендаций и более сложной проверки данных. Было решено сосредоточиться на надёжном учёте активности.

## Изменение 2. Выбор цели и уровня подготовки

**Планировалось:** после регистрации пользователь выбирает цель тренировок, уровень подготовки и доступные дни.

**Реализовано:** после регистрации пользователь может сразу перейти к привычкам, тренировкам и статистике.

**Причина:** эти данные использовались бы только для исключённой функции автоматического создания плана.

## Изменение 3. Готовые ежедневные тренировки

**Планировалось:** приложение показывает план на текущий день, упражнения, таймер и количество повторений.

**Реализовано:** приложение хранит историю тренировок, которые пользователь добавляет самостоятельно.

**Причина:** основной задачей продукта стал учёт выполненной активности, а не проведение тренировки по готовой программе.

## Изменение 4. Календарь и перенос тренировок

**Планировалось:** пользователь просматривает тренировки в календаре и переносит пропущенное занятие на другой день.

**Реализовано:** пользователь добавляет выполненные тренировки, после чего они отображаются в истории и статистике.

**Причина:** календарное планирование не является обязательным для учёта фактически выполненных тренировок.

## Изменение 5. Уведомления и напоминания

**Планировалось:** приложение отправляет уведомления о тренировках и привычках, позволяет отложить напоминание и повторяет его позже.

**Реализовано:** пользователь самостоятельно открывает приложение и отмечает выполнение привычек.

**Причина:** для уведомлений требуется дополнительная настройка фоновой работы на разных версиях Android. Приоритет был отдан серверному хранению данных и стабильности основных сценариев.

## Изменение 6. Параметры привычки

**Планировалось:** при создании привычки пользователь указывает название, частоту и время напоминания, а затем может редактировать привычку.

**Реализовано:** пользователь создаёт привычку, ежедневно отмечает её выполнение, просматривает серию выполнений и может удалить привычку.

**Причина:** частота и время напоминания были связаны с исключённой системой уведомлений. Основные функции трекера привычек сохранены.

## Изменение 7. Статистика по периоду

**Планировалось:** пользователь выбирает период отображения статистики — неделю или месяц.

**Реализовано:** приложение показывает общую статистику тренировок, их продолжительности, дистанции пробежек и привычек.

**Причина:** общая статистика была реализована как основная версия аналитического раздела.

## Добавленные возможности

Во время разработки были добавлены или уточнены функции, которых не было в первоначальных сценариях:

- отдельный экран профиля;
- сохранение токена и авторизации после перезапуска приложения;
- раздел помощи;
- выход из аккаунта;
- модульные тесты валидаторов электронной почты и пароля;
- автоматический запуск тестов с помощью GitHub Actions;
- Dockerfile и проверка сборки серверного Docker-образа.
