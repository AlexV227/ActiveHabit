# Окончательная заявка проекта ActiveHabit

## Автор

Водяников Александр Сергеевич, 11И7

## Название проекта

ActiveHabit: приложение для тренировок и трекер полезных привычек

## Тип проекта

Индивидуальный ИТ-проект.

## Целевая аудитория

Целевая аудитория проекта — молодые люди в возрасте от 16 до 30 лет, начинающие или любители фитнеса. Они хотят учитывать тренировки, пробежки и полезные привычки, а также видеть результаты своей активности в одном приложении.

## Проблемное поле

Людям бывает трудно регулярно заниматься физической активностью и формировать полезные привычки. Результаты тренировок и выполнения привычек часто не записываются или хранятся в разных приложениях. Из-за этого пользователю сложно следить за общим прогрессом.

Для проверки актуальности проекта был проведён опрос, в котором участвовал 21 человек. 90,5 % опрошенных занимаются физической активностью хотя бы иногда. 76,2 % хотя бы иногда записывают результаты тренировок, а 71,4 % хотя бы иногда отслеживают полезные привычки. Полезность объединения тренировок и привычек в одном приложении 71,4 % участников оценили на 4 или 5 баллов из 5.

Наиболее востребованными функциями оказались история тренировок — 85,7 %, общая статистика — 76,2 %, добавление тренировок — 66,7 %, подсчёт серии выполнений и учёт дистанции — по 57,1 %. Среди недостатков существующих приложений участники чаще всего называли платные функции — 57,1 % и необходимость использовать несколько разных приложений — 47,6 %.

## Образ продукта

Итоговый продукт — мобильное Android-приложение ActiveHabit. Оно позволяет пользователю зарегистрироваться и войти в аккаунт, просматривать профиль, учитывать привычки и тренировки, отмечать выполнение привычек и просматривать статистику.

Данные пользователей хранятся в удалённой базе данных PostgreSQL и загружаются после авторизации. Для взаимодействия Android-приложения с базой данных используется сервер с REST API.

## Аппаратные и программные требования

- операционная система Android 8.0 или выше;
- не менее 3 ГБ оперативной памяти;
- не менее 100 МБ свободной памяти;
- подключение к интернету для авторизации и загрузки данных.

## Функциональные требования

Приложение предоставляет следующие возможности:

1. Регистрация пользователя по имени, адресу электронной почты и паролю.
2. Вход зарегистрированного пользователя по электронной почте и паролю.
3. Сохранение авторизации после перезапуска приложения.
4. Просмотр профиля пользователя.
5. Создание и просмотр полезных привычек.
6. Ежедневная отметка выполнения привычки и подсчёт серии выполнений.
7. Удаление привычки.
8. Добавление тренировки с указанием вида и продолжительности.
9. Добавление пробежки с указанием дистанции в метрах.
10. Просмотр истории тренировок.
11. Просмотр общей статистики по тренировкам, их продолжительности, дистанции и привычкам.
12. Просмотр раздела помощи с объяснением основных действий.
13. Выход из аккаунта.

## Аналогичные продукты

### Adidas Running

Приложение предназначено прежде всего для учёта бега и других видов активности. Часть функций доступна только по платной подписке. В ActiveHabit учёт тренировок объединён с отслеживанием полезных привычек.

### Nike Training Club

Содержит готовые тренировки и программы занятий. Основная задача ActiveHabit отличается: пользователь самостоятельно добавляет выполненные тренировки и следит за общей статистикой вместе с привычками.

### Strava

Сервис ориентирован на запись спортивной активности и социальное взаимодействие. ActiveHabit имеет более простой интерфейс и объединяет историю тренировок с трекером привычек.

### Garmin Connect

Сервис предоставляет подробную статистику, но многие возможности рассчитаны на использование устройств Garmin. Для работы с основными функциями ActiveHabit дополнительное спортивное устройство не требуется.

## Инструменты разработки

### Клиентская часть

- Android Studio;
- Kotlin;
- XML-разметка;
- Fragments и Navigation Component;
- View Binding;
- Retrofit;
- Kotlin Coroutines;
- SharedPreferences для хранения токена авторизации.

### Серверная часть

- Node.js;
- Express;
- REST API;
- PostgreSQL;
- bcrypt для хеширования паролей;
- JWT для авторизации;
- dotenv для хранения настроек окружения.

### Дополнительные инструменты

- Git и GitHub для хранения исходного кода и истории разработки;
- GitHub Actions для автоматического запуска тестов;
- Docker для проверки контейнеризации серверной части.

## Структура базы данных

В проекте используются основные таблицы:

- `users` — данные учётных записей пользователей;
- `habits` — созданные пользователями привычки;
- `habit_completions` — отметки выполнения привычек;
- `workouts` — информация о тренировках и пробежках.

## Изменения по сравнению с первоначальной заявкой

Основная идея проекта не изменилась. ActiveHabit осталось Android-приложением для учёта тренировок и полезных привычек. Во время разработки были исключены автоматическое создание плана тренировок, выбор цели и уровня подготовки, календарь тренировок и уведомления. Вместо автоматического плана пользователь самостоятельно добавляет фактически выполненные тренировки и пробежки.

Эти изменения позволили сосредоточиться на стабильной работе регистрации, авторизации, хранения данных, привычек, тренировок и статистики. Подробное описание изменений находится в файле `changes.md`.

## Возможные риски и способы их снижения

- Нехватка времени — разделение разработки на небольшие этапы и выделение основной части времени летом.
- Недостаток знаний — изучение документации и дополнительных материалов, консультации с руководителем.
- Ошибки и нестабильная работа — тестирование функций после каждого этапа разработки.
- Проблемы безопасности — хеширование паролей, JWT-авторизация и хранение секретных настроек вне репозитория.
- Недоступность удалённого сервера — отдельная проверка сервера и всех пользовательских сценариев перед сдачей.
