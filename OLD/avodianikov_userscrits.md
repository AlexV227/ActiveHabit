## [ Сценарий 1 - Регистрация пользователя ]

1. Пользователь вводит логин для входа в систему
2. Пользователь вводит пароль
3. Пользователь вводит адрес электронной почты
4. Если логин уже существует, система сообщает об этом и предлагает придумать новый
5. Если пароль содержит менее 6 символов, система просит ввести более длинный пароль
6. Если email введён некорректно, система выводит сообщение об ошибке
7. Если все данные корректны, система создаёт аккаунт и авторизует пользователя
8. Пользователь переходит к настройке целей

## [Сценарий 2 - Настройка целей и уровня]

1. Пользователь выбирает цель тренировок: (похудение/набор формы/выносливость)
2. Пользователь выбирает уровень подготовки: (новичок/средний)
3. Пользователь выбирает доступные дни тренировок
4. После подтверждения система создаёт персональный план тренировок
5. Пользователь переходит на главный экран приложения

## [Сценарий 3 - Просмотр и выполнение тренировки]

1. Пользователь открывает вкладку «Тренировки»
2. Пользователь видит план на текущий день
3. Пользователь нажимает «Начать тренировку»
4. Система показывает список упражнений с таймером и повторениями
5. Пользователь выполняет упражнения и отмечает выполнение
6. Если пользователь пропускает тренировку, система предлагает перенести её на другой день
7. После завершения тренировки система сохраняет результат и обновляет прогресс

## [Сценарий 4 - Ввод данных беговой тренировки]

1. Пользователь открывает раздел «Бег»
2. Пользователь нажимает кнопку «Добавить пробежку»
3. Система открывает форму ввода данных
4. Пользователь вручную вводит:(дистанцию/время пробежки/дату выполнения)
5. При необходимости пользователь может указать комментарий (например, самочувствие или условия тренировки)
6. Если пользователь вводит некорректные данные (например, отрицательное число или пустое поле), система выводит сообщение об ошибке и просит исправить данные
7. После корректного заполнения пользователь нажимает «Сохранить»
8. Система сохраняет данные пробежки, обновляет статистику и отображает результат в истории тренировок

## [Сценарий 5 - Трекер привычек ]

1. Пользователь открывает раздел «Привычки»
2. Пользователь нажимает «Добавить привычку»
3. Пользователь вводит название привычки, частоту и время напоминания
4. Пользователь сохраняет привычку
5. Привычка появляется в списке
6. Пользователь ежедневно отмечает выполнение привычки
7. Система обновляет статистику и серию выполнений
8. Если день пропущен, серия обнуляется
9. Пользователь может редактировать или удалить привычку
10. Система показывает общий прогресс по привычкам

## [Сценарий 6 - Прогресс]

1. Пользователь открывает раздел «Прогресс»
2. Система отображает общую статистику по тренировкам, бегу и привычкам
3. Пользователь видит: (количество выполненных тренировок/суммарную дистанцию бега/количество выполненных привычек)
4. Пользователь может выбрать период (неделя/месяц)
5. Система обновляет статистику за выбранный период

## [Сценарий 7 - Уведомления и напоминания]

1. Система отправляет уведомления о тренировках и привычках
2. Пользователь получает уведомление и может:(открыть приложение/отметить выполнение/отложить напоминание)
3. Если пользователь игнорирует уведомления, система повторяет напоминание позже
