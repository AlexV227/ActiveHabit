# ActiveHabit: приложение для тренировок и трекер полезных привычек

ActiveHabit — индивидуальный ИТ-проект Водяникова Александра Сергеевича, ученика 11И7. Проект представляет собой Android-приложение для учёта тренировок, пробежек и выполнения полезных привычек.

## Назначение проекта

Приложение помогает хранить информацию о физической активности и привычках в одном месте. Пользователь может добавлять тренировки, отмечать выполнение привычек и просматривать общую статистику.

## Основные возможности

- регистрация и вход по электронной почте и паролю;
- JWT-авторизация;
- сохранение авторизации после перезапуска приложения;
- просмотр профиля;
- создание, просмотр и удаление привычек;
- ежедневная отметка выполнения привычек;
- подсчёт серии выполнений;
- добавление тренировок;
- ввод продолжительности тренировки;
- ввод дистанции пробежки в метрах;
- просмотр истории тренировок;
- статистика тренировок, времени, дистанции и привычек;
- раздел помощи;
- выход из аккаунта.

## Как устроен проект

Android-приложение отправляет HTTP-запросы к REST API с помощью Retrofit. Сервер обрабатывает запросы, проверяет токен пользователя и работает с PostgreSQL. Пароли сохраняются только в виде bcrypt-хеша. После успешного входа сервер выдаёт JWT-токен, который приложение хранит в SharedPreferences и передаёт при защищённых запросах.

Основные таблицы базы данных:

- `users`;
- `habits`;
- `habit_completions`;
- `workouts`.
