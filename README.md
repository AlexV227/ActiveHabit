ActiveHabit — приложение для тренировок и трекер полезных привычек

О проекте 

ActiveHabit — мобильное Android-приложение, предназначенное для учёта физических тренировок, формирования полезных привычек и отслеживания личного прогресса.
Проект разработан в рамках индивидуальной выпускной работы (ИВР) Лицея НИУ ВШЭ.

Цель проекта — создать работоспособный прототип мобильного приложения (MVP), объединяющего учёт тренировок и контроль выполнения привычек.

Основные возможности
1. Регистрация и авторизация
 	Создание учётной записи пользователя.
 	Вход в приложение по электронной почте и паролю.
 	Просмотр личного профиля.
 	Выход из аккаунта.
2. Трекер привычек
 	Добавление собственных привычек.
 	Просмотр списка привычек.
 	Отметка выполнения привычки за текущий день.
 	Отображение серии последовательных дней выполнения (streak).
 	Удаление привычек.
3. Учёт тренировок
    Добавление тренировки с указанием её вида и продолжительности.
    Для беговой тренировки можно указать дистанцию в метрах.
 	Автоматическая запись даты тренировки.
 	Просмотр истории сохранённых тренировок.
4. Статистика
 	Общее количество тренировок.
 	Суммарная продолжительность тренировок в минутах.
 	Количество созданных полезных привычек.
    Суммарная дистанция бега в метрах.

Используемые технологии

Мобильное приложение:	Kotlin, Android SDK

Среда разработки:	Android Studio

Серверная часть:	Node.js, Express.js

База данных:	PostgreSQL

Взаимодействие с сервером:	REST API, Retrofit

Авторизация:	JWT

Контроль версий:	Git, GitHub

Архитектура приложения

ActiveHabit состоит из трёх основных компонентов:
Android-приложение → REST API (Node.js / Express) → PostgreSQL
1.	Пользователь взаимодействует с интерфейсом Android-приложения.
2.	Приложение отправляет HTTP-запросы на сервер через Retrofit.
3.	Сервер проверяет запросы и выполняет необходимые операции с базой данных.
4.	PostgreSQL хранит сведения о пользователях, привычках, выполнении привычек и тренировках.
5.	Сервер возвращает ответ, после чего приложение обновляет интерфейс.
   
Структура базы данных
В PostgreSQL используются четыре основные таблицы:
 	users — учётные записи пользователей.
 	habits — созданные пользователями привычки.
 	habit_completions — даты выполнения привычек.
 	workouts — сведения о тренировках.
  
Данные пользователей разделены: каждый авторизованный пользователь работает со своими записями.

В будущем приложение можно дополнить графиками прогресса, напоминаниями о привычках, календарём тренировок и расширенной аналитикой.
Эти функции не входят в текущую версию MVP.

Запуск серверной части

1. Установить Node.js и PostgreSQL.
2. Открыть папку server.
3. Установить зависимости:

npm install

4. Создать файл .env на основе .env.example.
5. Создать таблицы базы данных:

psql -U activehabit_user -d activehabit -h localhost -f schema.sql

6. Запустить сервер:

node index.js

После запуска сервер работает по адресу .
